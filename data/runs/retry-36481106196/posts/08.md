*Описание:* OpenCodeReview — CLI‑утилита для автоматизированного ревью кода, разработанная в Alibaba и теперь открытая для сообщества\. Инструмент читает Git‑diff, отправляет изменённые файлы в LLM‑агента \(поддерживает OpenAI, Anthropic, Claude Code и др\.\) и генерирует структурированные комментарии с точностью до строки, умея искать по всему репозиторию и анализировать полные файлы через команду ocr scan\. Встроенный набор правил \(NPE, thread‑safety, XSS, SQL‑injection\) повышает точность, а гибридная архитектура \(детерминированные пайплайны \+ LLM‑агент\) экономит токены ≈ 1/9 по сравнению с обычными агентами\. Подойдёт инженерам, которым нужен быстрый, масштабируемый и «прецизионный» AI‑ревью для многоплатформенных проектов, особенно в больших командах, где важна минимизация ложных срабатываний\.
