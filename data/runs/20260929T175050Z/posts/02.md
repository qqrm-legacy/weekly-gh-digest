*Описание:* Проект «Claude Code Templates» — это набор готовых конфигураций для Anthropic Claude Code, упакованный в CLI‑утилиту\. С помощью одной команды npx пользователь может установить готовые агенты \(например, frontend‑developer\), кастомные команды, настройки, хуки и внешние интеграции \(MCP\), включая готовый набор Bright Data‑skills для веб‑поиска и скрапинга\. Инструмент ориентирован на разработчиков, желающих быстро расширить возможности Claude Code в CI/CD, ревью кода, тест‑генерации и прочих задачах без ручного написания шаблонов\. При установке компонентов автоматически добавляются зависимости, но стоит помнить, что работа требует доступа к внешним сервисам \(Bright Data, GitHub\) и соответствующих токенов\.
