## [Alishahryar1/free-claude-code](https://github.com/Alishahryar1/free-claude-code)

Free Claude Code (FCC) — это клиент‑агрегатор, позволяющий пользоваться более чем десятком код‑ориентированных LLM‑интерфейсов (Claude Code, Codex, Pi, OpenCode, Antigravity CLI, VS Code Chat и др.) через единый набор команд. Проект поддерживает 61 провайдера, включая бесплатные тарифы, и обещает более 1,3 млрд бесплатных токенов в месяц, автоматически распределяя запросы между моделями и ключами, а также переключаясь на резервные сервисы при сбоях. Для снижения расходов включены оптимизаторы RTK и Headroom, которые могут уменьшить потребление токенов до 90 %.

Пользователь может запускать FCC из терминала, настольных приложений, IDE‑расширений, мобильных мессенджеров (Discord, Telegram) и даже из браузера через «native Code sessions», где сохраняются нативные потоки, поддержка инструментов и чередование «thinking». Голосовые заметки обрабатываются локально Whisper или NVIDIA NIM, что расширяет возможности взаимодействия без ввода текста. Конфигурация включает автоматические повторные попытки, ограничение скорости, контроль параллелизма и гибкую настройку провайдеров, что повышает надёжность при перебоях у отдельных сервисов.

Сценарий применения: разработчик, работающий над проектом в VS Code, подключает FCC, выбирает бесплатный провайдер и получает доступ к Claude Code, Codex и другим моделям без необходимости менять настройки каждого инструмента. При превышении лимита одного провайдера система автоматически переключается на альтернативный, сохраняя контекст и поток вывода. Основные ограничения — зависимость от условий бесплатных тарифов провайдеров (лимиты могут изменяться) и необходимость установки дополнительных компонентов (Whisper, RTK, Headroom) для полной функциональности.

## [QwenLM/qwen-code](https://github.com/QwenLM/qwen-code)

Qwen Code — это открытый AI‑агент, который работает прямо в терминале и может быть подключён к редакторам, настольным и веб‑приложениям, а также к чат‑ботам. После установки пользователь запускает команду `qwen`, а агент принимает запросы в естественном языке, например «Explain this repository and show me where to start», и генерирует ответы, используя выбранный провайдер LLM (OpenAI, Anthropic, Gemini, Qwen, локальные модели через Ollama или vLLM). Внутри агент поддерживает автопамять, автоскills, суб‑агенты и команды‑команды, что позволяет создавать динамические рабочие процессы без дополнительной настройки.

Проект предлагает готовые интеграции: плагины для VS Code, JetBrains, Zed, а также клиентские приложения для Windows, macOS и Linux, и чат‑интеграции (Telegram, DingTalk, WeChat, Feishu). Пользователь может переключать провайдеры «на лету», задавая API‑ключи или используя подписку Qwen Account, что упрощает переход между облачными и локальными моделями. Кроме того, Qwen Code сам использует свои модели для автоматизации разработки: он открывает issues, отправляет pull‑request‑ы, проверяет код и запускает тесты, демонстрируя «self‑iterating» подход.

Типичный сценарий: разработчик открывает проект, запускает `qwen`, просит агента проанализировать кодовую базу и предложить план рефакторинга. Агент отвечает, генерирует патчи, создаёт PR и проверяет их тестами, всё в одном интерактивном сеансе. Требования включают Node.js ≥ 22 для npm‑установки и доступ к выбранному LLM‑провайдеру; без подписки или API‑ключа функциональность ограничена. Ограничения: работа зависит от внешних моделей, поэтому без подключения к провайдеру или локальному серверу агент не сможет генерировать ответы.

Пользователь выбирает одну из двух предопределённых конфигураций задач: представление в обобщённых координатах (SuperMimic-GenCoord-G1) или в максимальных координатах (SuperMimic-MaxCoord-G1), после чего запускает скрипт train.py для совместного обучения модели мира и политики управления, используя GPU‑ускорение через uv‑runtime. После обучения модель можно воспроизвести с помощью play.py, указав путь к запущенному эксперименту в wandb, что упрощает визуализацию и отладку полученных движений. Платформа поддерживает гибкую интеграцию с внешними репозиториями, требуя лишь клонирования SuperMimic и mjlab_research как соседних каталогов, а установка uv обеспечивает изоляцию зависимостей без необходимости глобального pip. Среди ключевых преимуществ: единая дифференцируемая модель мира, позволяющая одновременно обучать восприятие и контроль; два готовых представления координат, дающих исследователям возможность сравнивать эффективность разных параметризаций; и открытый код, вдохновлённый проектами ControlVAE, robotic_world_model и DreamerV3, что облегчает расширение и адаптацию под собственные задачи. Для работы требуется GPU с поддержкой CUDA и установленный uv; ограничение состоит в том, что текущая реализация ориентирована на симуляцию в MuJoCo и не предоставляет готовых средств для реального робота без дополнительной интеграции.
