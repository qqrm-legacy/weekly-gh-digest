[debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio)
⭐ 47254 всего · \+7972 в недельном Trending · Python

*Описание:* VoiceStudio — полностью локальная альтернатива ElevenLabs, предоставляющая клон голоса, дизайн голоса, дубляж видео, диктовку, транскрипцию и создание аудиокниг более чем на 646 языках\. Приложение‑клиент на Electron работает с несколькими движками \(по умолчанию k2‑fsa/OmniVoice\) и позволяет управлять локальными моделями, а при желании подключать удалённые сервисы через локальный API и MCP\. Подойдёт разработчикам, контент‑создателям и агентам‑ботам, которым нужен полностью оф‑лайн генератор речи без отправки данных в облако\. Техническая оговорка: для сборки из ветки main требуются Node 22\+, Bun, Rust/Cargo и набор инструментов сборки, иначе установка завершится ошибкой\.
