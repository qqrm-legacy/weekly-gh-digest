## [xcl-dev/xcl](https://github.com/xcl-dev/xcl)

XCL — это слой совместимости, позволяющий запускать нативный x64‑код Xbox Series X|S (GDK) на Windows без эмуляции процессора. Проект реализует собственные версии системных библиотек консоли (kernelx.dll, XGameRuntime, d3d12_xs.dll и т.д.) и перекомпилирует машинный код GPU RDNA2 в HLSL‑DXIL, благодаря чему шейдеры работают без ошибок. Среди поддерживаемых функций — загрузка PE‑файлов, управление памятью, файловая система с оверлей‑записью, DirectStorage‑очереди и полный набор сервисов XGameRuntime, включая ввод через XInput и аудио через XAudio2. Пользователь может запускать распакованные файлы собственных игр, получая полностью играбельный опыт, как показано на примерах Minecraft Preview, Fortnite и XDefiant, при этом XCL не содержит DRM‑обхода, SDK‑кодов или игровых данных. Ограничения: требуется предварительно распакованный пакет игры, поддержка ограничена текущим набором реализованных библиотек и шэйдеров, а онлайн‑зависимые функции (мультиплеер, серверы) работают только в рамках доступных сервисов.

## [ubiquitarianism/leonida](https://github.com/ubiquitarianism/leonida)

Проект — статическая перекомпиляция оригинальной версии GTA VI для Xbox Series, позволяющая запускать её нативно на Windows. Благодаря тому, что процессор консоли — x86‑64, код игры загружается и исполняется без эмуляции, а системное ПО консоли воссоздаётся в виде пользовательского рантайма. Преобразователь переводит предкомпилированные RDNA2‑шэйдеры в SPIR‑V, что делает их совместимыми с Vulkan‑драйверами разных производителей. Все модели, текстуры и аудио извлекаются из вашей копии игры и остаются на локальном диске, без передачи в облако.

Ключевые возможности: полностью реализована проверка и перевод всех 26 503 шэйдеров (2 236 вершинных, 12 101 пиксельных и др.) с подтверждённой валидацией SPIR‑V; экспорт моделей в OBJ‑формате, уже извлечено более 380 000 моделей, включая почти весь контент уровней; поддержка широкого спектра GPU (AMD, NVIDIA, Intel, Apple) через тесты, проверяющие работу шэйдеров, текстур и вычислительных блоков. На текущий момент игра ещё не загружается, но инфраструктура для загрузки, проверки копии и трансляции шэйдеров полностью готова, что позволяет разработчикам сразу приступить к отладке загрузочного процесса, имея все необходимые артефакты.

Сценарий использования: пользователь копирует файлы Xbox‑версии GTA VI на ПК, запускает сборку проекта, которая извлекает ресурсы, переводит шэйдеры и формирует директорию с готовой к запуску средой. Затем, получив исполняемый файл игры (не предоставляемый репозиторием), можно попытаться запустить его через созданный рантайм. Требования включают наличие рабочей копии игры, поддерживаемый Vulkan‑драйвер и компилятор LLVM 23.x; ограничения — отсутствие текущей возможности загрузки и отсутствие каких‑либо средств обхода защиты, проект работает только с легально полученными данными.

## [Avaneesh-Inamdar/Stream-Tube-Desktop](https://github.com/Avaneesh-Inamdar/Stream-Tube-Desktop)

Stream Tube – это нативный клиент YouTube для Windows и Linux, написанный на Rust. Приложение заменяет браузер, полностью избавляя от рекламных роликов, спонсорских вставок и трекинга, поскольку видео воспроизводятся через libmpv без загрузки рекламных потоков. Встроенные модули SponsorBlock, DeArrow и Return YouTube Dislike автоматически пропускают рекламные сегменты, заменяют заменённые титры и показывают оригинальные оценки, что делает просмотр чище и быстрее.

Пользователь получает привычный набор функций: лента Home, Shorts, подписки, поиск с подсказками, плейлисты и возможность открывать контент в нескольких вкладках, управляемых привычными сочетаниями клавиш. Воспроизведение поддерживает аппаратное декодирование, выбор кодека (AV1, VP9, H.264), разрешения от 360p до 4K, а также расширенные возможности плеера – стилизованные субтитры, панель глав с главами, тайм‑коды в описаниях и комментариях, мини‑плеер, PiP и автоплей. Приложение сохраняет позицию просмотра, качество и скорость воспроизведения, а также умеет показывать старые аннотации YouTube и поддерживает RTL‑текст.

Для пользователей, которым нужен быстрый, лёгкий и рекламно‑чистый доступ к YouTube без постоянного открытого браузера, Stream Tube предлагает полностью нативный UI, отрисованный GPUI, и небольшое потребление памяти по сравнению с Electron‑решениями. Требования ограничиваются наличием GPU‑поддержки для рендеринга и установленного libmpv; приложение не предоставляет собственного бэкенда и полагается на публичные API YouTube, поэтому при изменениях в этих API возможны сбои, как и у любого стороннего клиента.
