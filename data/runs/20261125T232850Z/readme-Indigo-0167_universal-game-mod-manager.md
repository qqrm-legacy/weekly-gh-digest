**Universal Game Mod Manager is a free, open-source Windows desktop application for discovering, installing, updating, and managing universal PC game mods.** Designed for gamers and VR enthusiasts, it makes cross-game modding accessible through a simple graphical interface, with no command line required.

## ⬇️ Installation

**Download the Windows application**

1. Open the repository's [Releases](https://github.com/Indigo-0167/universal-game-mod-manager/releases) page.
2. Download the latest release archive **`Universal Game Mod Manager 4.0.3.zip`**.
3. Extract the archive into a folder of your choice.
4. Keep **`Universal Game Mod Manager 4.0.3.exe`** and `libvlc.dll` together in that folder.
5. Double-click **`Universal Game Mod Manager 4.0.3.exe`** to launch the application.


## ✨ Features

- 🎮 **Automatic Game Discovery** — Find installed PC games across supported game launchers without manually searching through installation directories.
- 🧩 **Universal Mod Installation** — Discover and install compatible mods designed to work across multiple games using the same underlying engine.
- 🔍 **Game Engine Detection** — Identify whether a game uses Unity, Unreal Engine, or another supported technology and detect relevant engine information.
- 🚀 **Unreal Engine Mod Support** — Manage universal Unreal Engine modifications and compatible tools for supported games.
- 🔄 **One-Click Mod Updates** — Check for newer mod releases and conveniently update installed components.
- 📚 **Centralized Mod Library** — Keep track of supported games, installed modifications, and available versions from one desktop application.
- 🖥️ **Multi-Store Game Detection** — Discover games from supported PC gaming platforms, including Steam, GOG, Epic Games, itch.io, and Xbox.

## 🖼️ Overview

![Features](assets/features.png)

### A smarter approach to PC game modding

Traditional mod managers often focus on individual games. Universal modding tools take a different approach: one modification can potentially support multiple games built on the same engine.

This application helps bridge that gap by identifying games, detecting their technical characteristics, and making relevant universal modifications easier to manage.

### Supported game discovery

The application can inspect locally available game library information to identify games from supported providers.

| Game platform | Installed games | Owned games |
|---|---|---|
| Steam | Automatic detection | Library detection |
| GOG | Automatic detection | Library detection |
| Epic Games | Automatic detection | Library detection |
| itch.io | Automatic detection | Library detection |
| PC Xbox | Supported installations | Not currently supported |
| Other platforms | Manual management | Manual management |

**Note:** Discovery capabilities depend on the platform, available local metadata, and game installation configuration. Some games may need to be added manually.

### Universal game mod compatibility

Universal mods are particularly useful for games sharing an engine or compatible technical foundations.

Examples of universal modding ecosystems include:

- **Unity** — Tools and modifications designed for compatible Unity-based games.
- **Unreal Engine** — Cross-game modification frameworks for supported Unreal Engine titles.
- **VR modding** — Universal virtual reality modifications that bring VR experiences to compatible PC games.

Compatibility is determined by each mod's requirements, supported engine versions, and individual game configuration. Not every modification works with every game.

## 🚀 Usage

Getting started with universal PC game mod management is straightforward:

1. **Launch the application** — Open Universal Game Mod Manager on your Windows desktop.
2. **Discover your games** — Allow the application to scan supported game libraries and identify available installations.
3. **Review game information** — Check detected engines, versions, and other relevant compatibility information.
4. **Explore compatible mods** — Find universal modifications that match your games and their technical requirements.
5. **Install your mods** — Select a compatible modification and follow the available installation workflow.
6. **Manage updates** — Return to your mod library to check for updates and maintain your installed modifications.

**Tip:** Keep your games and mod frameworks updated. Engine updates can affect compatibility with existing universal mods.

## ❓ Frequently Asked Questions

### What is a universal game mod?

A universal game mod is a modification or framework designed to support multiple compatible games instead of being built exclusively for one specific title.

### Does this work with Unity games?

The application supports identifying relevant Unity game information to help with compatible universal mod workflows. Actual mod compatibility depends on the individual modification.

### Does this support Unreal Engine games?

Yes, it is designed to help manage universal modding workflows for compatible Unreal Engine games.

### Can it find my Steam games automatically?

It can discover available Steam library information, including supported installed games and relevant library entries. Detection may vary depending on your Steam configuration.

### Do I need programming knowledge?

No. The application provides a graphical desktop interface, so normal game discovery and mod management do not require command-line knowledge.

### Is it free?

Yes. The project is open source and distributed under the MIT License.

### Does every universal mod work with every game?

No. Universal mods still have compatibility requirements. Engine versions, game implementations, and mod-specific dependencies can affect whether a particular modification works.
